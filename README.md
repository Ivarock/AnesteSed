🌙 AnesteSed: Calculadora de Sedación Procedimental

AnesteSed es una aplicación web progresiva (PWA) para calcular dosis de fármacos en sedación procedimental, en adultos y pediatría. Funciona 100 % sin internet y no guarda datos de pacientes.

App: https://ivarock.github.io/AnesteSed/

Qué hace
- Paciente: edad (años o meses), sexo, peso, talla, ASA y fragilidad. Calcula peso ideal (Devine), corregido (factor 0.4) y magro (Janmahasatian), y en obesidad usa el peso adecuado para cada fármaco.
- Sedación: eliges el nivel (mínima, moderada o profunda) y los fármacos o una combinación frecuente (midazolam + fentanilo, propofol + fentanilo, ketofol, ketamina + midazolam, dexmedetomidina + propofol). Midazolam, fentanilo, propofol, ketamina, dexmedetomidina y remifentanilo.
- Ajusta las dosis al combinar fármacos y por edad, ASA y fragilidad; aplica topes y límites de edad pediátricos.
- Presentación y dilución de cada fármaco, con instrucciones de preparación y volúmenes en mL o mL/h.
- Antídotos: naloxona y flumazenil para adultos y niños.
- Fuentes: cómo calcula y referencias (ASA, AAP/AAPD, ACEP, Merck, CGO, CHOP, fichas técnicas FDA, Miller).

📲 Instalación
Abre el enlace una vez con internet y toca "📲 Instalar AnesteSed" (Android, Chrome) o Compartir → "Agregar a inicio" (iPhone, Safari).

⚠️ Herramienta de apoyo para profesionales entrenados, en un entorno monitorizado y con capacidad de rescate de la vía aérea. No sustituye el juicio clínico, el protocolo institucional ni la ficha técnica.
